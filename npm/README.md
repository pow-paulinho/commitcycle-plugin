# commitcycle

`cycle` — the [CommitCycle](https://commitcycle.com) CLI. Least privilege for
AI coding agents: zones with owners, a five-state board with a gate, and grants
bound to one task and one branch.

```
npm i -g commitcycle
cycle init
```

The command is `cycle` because `cc` is your C compiler, and a governance
tool must never shadow a compiler.
